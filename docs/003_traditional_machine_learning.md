# 传统机器学习情感分类

## 实验目的

使用 TF-IDF 表示 IMDB 评论，分别训练逻辑回归和线性支持向量机，建立后续 CNN、LSTM 和模型融合实验的传统机器学习基线。同时比较不同 N-gram 特征对分类结果的影响。

## 数据与特征

使用清理后的训练集（22,413 条）和验证集（2,491 条）。去重后的测试集保留到最终评估，不用于选择模型或参数；由于去除了重复评论，它与原始官方测试集并不完全相同。

TF-IDF 转换器只在训练集上拟合，再转换验证集。三种特征分别为 Unigram、Bigram 和 Unigram + Bigram，均设置 `min_df=2`、`max_features=20000`。组合特征的 20,000 个位置由单词和双词共同使用，并不是另外两组特征的直接拼接。重新生成训练数据后，需要重新拟合并保存转换器。

## 分类模型

逻辑回归将特征的线性组合转换为正类概率，训练时通过优化对数损失和正则化项确定权重。线性支持向量机根据线性决策函数判断类别；这里的 `LinearSVC` 使用平方 hinge 损失和正则化。两种方法都通过数值优化求解参数，`max_iter` 限制最大迭代次数，而非指定训练轮数。

`C` 控制分类损失与正则化之间的权衡，通常 C 越小，正则化作用越强。两种模型的优化目标不同，相同的 C 不表示相同的正则化效果。本阶段的六组基线均使用 `C=1.0` 和 `max_iter=1000`；Linear SVM 固定 `random_state=42`。

## 评价与结果

验证集记录 Accuracy、Precision、Recall 和 F1；后三项以正面评论（标签 1）为正类。Notebook 还比较了混淆矩阵、预测分歧和部分错误样本。

当前六组实验中，组合特征搭配 Linear SVM（B06）获得最高的验证集 Accuracy（0.8876）和 F1（0.8889），但与 Unigram 搭配 Linear SVM（B04）的差异很小。仅使用 Bigram 的两组表现低于各自模型使用 Unigram 或组合特征的结果。B01 与 B06 的错误并不完全重合，但这不意味着融合一定会提高性能。

固定组合特征对 Linear SVM 比较 `C=0.1、1.0、10.0`，其中 `C=1.0` 的验证集 F1 最高。B06 暂作传统机器学习代表；这些是同一验证集上的探索结果，不构成测试集结论，也不代表其他数据集上的普遍表现。

## 复现

先按 `001`、`002`、`003` 的流程准备数据并保存三个 TF-IDF 转换器，然后从项目根目录运行：

```powershell
python scripts/traditional_ml.py
```

脚本训练六组基线并比较 B06 的 C 值，将验证集结果表保存到 `reports/tables/`；Notebook 中的探索、图表和错误分析保留在 `004_traditional_ml.ipynb`，图表保存到 `reports/figures/`。脚本和 Notebook 均依赖可导入的 `sentiment_analysis` 包，以及与已保存转换器兼容的 Python 和 scikit-learn 环境。

本次结果使用 Python 3.12.7、scikit-learn 1.8.0、pandas 2.2.2、NumPy 1.26.4 和 joblib 1.4.2。数据和转换器位于被 Git 忽略的 `data/` 下，需按上述步骤自行生成。
