# 项目概述

大致流程如下

数据准备（数据预处理，划分训练集，测试集，验证集）

做传统分类任务

做CNN分类

做LSTM分类

做模型互补分析

做效果评估

做bert


1. Introduction — 情感分类背景、研究问题与研究动机。

2. Related Work — 传统机器学习、CNN、LSTM、集成学习和预训练 Transformer。

3. Dataset and Methodology — IMDB 数据、预处理、模型结构、训练与评价方法。

4. Baseline Experiments — TF-IDF、CNN、LSTM 的实验结果。

5. Ensemble Learning Analysis — 融合策略、权重搜索、模型互补性与错误分析。

6. DistilBERT Extension — 预训练 Transformer 实验与性能比较。

7. Discussion — 性能差异、计算成本、局限性和研究启示。

8. Conclusion — 回答研究问题，提出可能的进一步研究方向。
